# Conexium Engenharia

Site institucional da Conexium Engenharia, marca técnica especializada em engenharia elétrica, conexão à rede, consultoria técnico-regulatória, perícias, inteligência energética e infraestrutura para novas cargas.

## Stack

- Astro
- Tailwind CSS
- Markdown Content Collections
- Vitest
- Playwright

## Comandos

```bash
pnpm install
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
pnpm audit:links
```

## Deploy

O domínio canônico configurado é `https://conexiumengenharia.com.br`.

Enquanto a publicação definitiva em domínio próprio não estiver ativa, o deploy técnico pode continuar usando GitHub Pages com `PUBLIC_BASE_PATH=/kairos-engenharia`.
