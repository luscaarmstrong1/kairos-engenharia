# Conexium Engenharia - Contexto do Projeto

## 1. Contexto

Conexium Engenharia é a nova marca técnica/comercial aplicada ao site institucional existente. A marca atua em engenharia elétrica, conexão à rede, consultoria técnico-regulatória, perícias, quesitos técnicos, inteligência energética, geração distribuída, eletromobilidade e infraestrutura para novas cargas.

## 2. Assinatura

Engenharia, conexão e inteligência técnica para o setor elétrico.

## 3. Aviso Institucional

A Conexium Engenharia é uma marca técnica utilizada por Renovera Energias Renováveis Ltda. Os serviços são prestados conforme escopo técnico contratado, com emissão de ART quando aplicável.

## 4. Estrutura Técnica

- Site em Astro com Tailwind CSS.
- Conteúdos técnicos estáticos em Markdown.
- Domínio canônico previsto: `https://conexiumengenharia.com.br`.
- Base técnica temporária de GitHub Pages parametrizada por `PUBLIC_BASE_PATH`.
- E-mails parametrizados em configuração central: `contato@conexiumengenharia.com.br` e `lucas@conexiumengenharia.com.br`.
